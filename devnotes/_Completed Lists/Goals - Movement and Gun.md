After playing Destiny for a bit, here are some things I noticed in the movement that would be helpful to incorporate.
- [x] Sprinting immediately un-crouches when still
- [x] Sprinting un-crouches after the slide ends
- [x] Toggle Sprint
- [x] Toggle Crouch
- [x] Crouch has weight/Friction and its noticeable
- [x] There is a VERY small amount of weight on turn
	- IE turning 180 to the right moves you a tad to the right
- [x] Jump is super smooth and has no hang time.
- [x] Variable jump is super subtle, and feels like a full jump

Things I noticed about the weapon (Auto rifle)
- [x] On fire, it kicks back a set amount (Full after 2, large jump after 1st shot, bit more after second to final position) and up (super subtle) visually a small amount
- [x] Vibrates slightly on fire
- [x] Recoil is not straight up, there is a slight left-right
- [x] Bullet has a slight spread left-right
- [x] Faint bullet line if energy
- [x] Bullet visible if kinetic is small bright pellet with faint smoke line, but seems to vanish by the time it hits hit marker
- [x] Muzzle flash is not set, its random, but matches the weapon, and is rather large (At least size of weapon width)
- [x] Recoil slowly resets after to original position. IE if you hold it and camera goes up to 65 degrees, it will return back to 0 after you stop firing.
	- Bullet spread builds over time
- [x] Hit marker that flashes (x) on hit, white damage numbers with yellow on precision
- [x] Cross hair is a circle, not a point, and it expands with recoil
- [ ] Cross hair turns red over enemy
- [x] Damage numbers fade in, move sideways (Fast -> still pace), pop out of existence
- [x] Precision damage numbers are slightly bigger
